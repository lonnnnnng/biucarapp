# Biu Car 模拟器验收记录

## 验收环境

- AVD：`CASKA_1024x600`
- serial：`emulator-5554`
- Android：8.1 / API 27 / arm64-v8a
- 显示：1024×600 / 160 dpi
- 内存：1536MB

## 自动化检查

```zsh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --no-daemon --console=plain
```

覆盖 TV 二维码状态码映射、成功 Cookie 解析、缺失 `expires_in` 的兜底有效期、APPKey 签名和 WBI 签名稳定性。

## 已验证

- Debug APK 可安装并从 Launcher 启动，冷启动日志未出现 FATAL 或 ANR。
- 目标分辨率与密度正确，首页、媒体库历史页、账号页、二维码页和播放页无裁切或重叠。
- 首次使用且首页 UP 配置为空时，首页不请求默认推荐内容。
- TV 二维码申请接口返回成功；界面生成可扫描二维码并持续显示“等待扫码”。
- 系统状态栏和导航栏与应用深色主题一致。
- MediaController 能绑定 `CarPlaybackService`，空闲 PSS 约 58.5MB，无 Swap。
- 本地历史在未登录状态仍可进入，在线收藏和首页 UP 配置会明确引导登录。

## 仍需账号人工确认

以下步骤必须由用户在哔哩哔哩 App 中扫码并确认，本轮未代替用户授权账号登录：

1. 扫码成功后 `/x/web-interface/nav` 返回 `isLogin=true`。
2. 读取真实关注列表并保存首页 UP 配置。
3. 读取“我创建的”“我收藏的”真实收藏内容。
4. 播放真实 DASH AAC 音轨直至完整缓存完成。
5. 关闭网络后，从离线历史恢复播放并续播保存进度。

## 工具兼容说明

`android-emulator-install` skill 能正确构建并启动可见 AVD，但其设备识别只读取 `ro.boot.qemu.avd_name`。该 API 27 镜像只提供 `ro.kernel.qemu.avd_name=CASKA_1024x600`，因此脚本会误报 AVD 未出现。验收先由 skill 以 supervised 模式启动 AVD，再在已核对 serial 和内核 AVD 属性后对 `emulator-5554` 执行显式安装。
